# 白龍桌寵 Companion（二創版）

基於 [jingh12312-rgb/bailong-desktop-pet](https://github.com/jingh12312-rgb/bailong-desktop-pet) 進行個人化功能追加的 **二次創作版本**。感謝原作者提供白龍桌寵及動畫素材；本倉庫不是原作者的官方版本。

保留原版桌面角色、待機動畫、拖曳及 Codex 額度查詢，在此基礎上增加會記憶、能延續關係的角色互動。

## 相較原版的改動

- 介面與設定翻譯為繁體中文，動畫預覽集中於右鍵子選單。
- 單擊開啟半透明淡紫色輸入框，回覆以文字泡泡浮現，依文字長度調整停留時間。
- 支援 ChatGPT 帳號通道及 Gemini API Key 通道，兩種服務分別保存模型選擇。
- 透過本機 `Character.md` 定義核心人設，保留近期對話並整理較早的上下文。
- 長期記憶可累積與管理；關係、信任及心情會隨互動變化。
- 回覆搭配心情標籤選擇動畫，並提供動作回退與播放優先序。
- 每分鐘嘗試播放日常小動畫，每 40～80 分鐘安排主動事件。
- 主動事件可根據多螢幕桌面快照開啟互動；先經本機 OCR 敏感資訊檢查，檢查失敗或判定敏感即略過。
- 可累積「白龍的觀察日記」，達到關係與日記門檻後有機會觸發隱藏事件。
- Codex 工作完成播放「靈感」與「主人我做好了喔」；五小時剩餘額度不超過 10% 時播放「14 困倦」及固定提醒，不呼叫語言模型。
- Google Drive 手動同步人設、對話、記憶、關係及日記；版本不同由使用者決定，不自動覆寫。
- Windows 登入資料與 API Key 使用 DPAPI 加密保存。

## 執行與建置

支援 Windows x64。此倉庫保存原始碼、設定範例及測試；不包含 Python／Qt 執行環境、Codex 執行檔或大型動畫素材。完整可攜版與原始碼是不同用途的發佈形式。

1. 依原作者提供的素材與使用權取得完整動畫資源，放入 `outputs/白龙桌宠素材/`。
2. 依 [開發與建置說明](docs/DEVELOPMENT.md) 建立 Python 環境。
3. 複製 `Character.example.md` 為 `Character.md`，自行撰寫角色人設。
4. 執行 `app/pet.py`，或使用 `Build-BailongPet.ps1` 編譯。

### Gemini

右鍵 → 參數設定 → 選擇 Gemini → 儲存自己的 API Key → 重新載入模型。支援新版授權金鑰的句點及較長內容；儲存後仍須由 Google 驗證權限與配額。

免費額度依 Google 帳號、所在地、專案及所選模型而定，不保證無限或永久免費。[設定方式與隱私說明](docs/Gemini.md)。

### Google Drive

使用自己的 Google Cloud 桌面 OAuth 用戶端，啟用 Drive API；每台電腦匯入相同 OAuth JSON，登入相同 Google 帳號，選取原有白龍版本。先支援一次一台電腦使用。[同步設定與使用](docs/GoogleDrive.md)。

## 隱私與資料

- 不包含使用者的 `Character.md`、聊天、記憶、關係、觀察日記、帳號、OAuth JSON 或 API Key。
- 回覆會傳送人設及相關對話與記憶到使用者選定的模型服務；桌面事件亦會傳送通過本機檢查的快照。OCR 無法保證辨識所有敏感資訊，可自行停用桌面事件。
- Gemini 免費服務的輸入與輸出可能用於改善產品；依 Google 最新條款為準。
- Google Drive 同步不會上傳登入憑證、API Key 或桌面快照；同步內容未另做端對端加密。
- ChatGPT／Gemini 的可用模型、帳號資格與用量限制由服務供應商決定。

## 驗證

目前版本已通過 297 項回歸測試與編譯版離線檢查。Gemini 的模型回覆使用模擬 API 驗證，實際權限、免費配額及回覆品質需使用自己的帳號驗收。Google Drive 已進行實際人工同步測試。
