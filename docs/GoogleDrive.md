# 白龍 Google Drive 同步記憶

這一版以「手動同步、一次一台電腦」為原則。開啟白龍後，至右鍵「參數設定 → 同步記憶 · Google Drive」。不需要安裝 Google Drive 桌面版。

## 第一次：建立 Google OAuth 設定

此步驟只需由你建立一次，各台電腦使用同一份設定檔。

1. 開啟 [Google Cloud Console](https://console.cloud.google.com/)，使用你的 Google 帳號登入，建立一個專案，例如 `Bailong Desktop Pet`。
2. 選定該專案，在「API 和服務 → 程式庫」搜尋 **Google Drive API**，按啟用。
3. 開啟 **Google Auth Platform**。依提示設定應用程式名稱、支援信箱及聯絡信箱。
4. 在「目標對象／Audience」設定個人測試所需的 External／外部使用者與測試模式，將你要同步的 Google 信箱加入測試使用者。
5. 在「資料存取／Data Access」確認應用使用的範圍包含 `https://www.googleapis.com/auth/drive.appdata`，以及基本帳號辨識的 `openid`、`email`。
6. 在「用戶端／Clients」建立 OAuth 用戶端，類型選 **Desktop app／桌面應用程式**，不要選 Web application。
7. 下載該用戶端的 **JSON 設定檔**。
8. 回到白龍的同步視窗，按「匯入 OAuth 設定」選取剛才的 JSON，再按「登入 Google」，在瀏覽器同意授權。

Google 的介面名稱可能依語言略有差異。白龍視窗內的「第一次設定說明」也提供步驟。

**各台電腦必須使用同一份 OAuth JSON，並登入同一個 Google 帳號**，才能看到同一個應用程式資料空間。若使用不同 Google Cloud 用戶端，可能看不到先前的白龍紀錄。

OAuth JSON 不需要貼到聊天，也不應放進要分享的可攜壓縮包。白龍會將匯入的設定與 Google 權杖用 Windows DPAPI 加密保存；不會把它們上傳成記憶。

如果登入被拒絕，先確認 Drive API 已啟用、用戶端類型為桌面應用程式、目前 Google 帳號已加入測試使用者。測試模式下可能需要定期重新登入。

## 第一次同步

1. 先登入白龍聊天使用的 ChatGPT 帳號，讓程式知道要同步哪一份本機紀錄。
2. 開啟「參數設定 → 同步記憶 · Google Drive」，登入 Google。
3. 按「檢查雲端版本」。
4. 尚未建立雲端紀錄時，選「建立新的白龍雲端紀錄」。
5. 按「比較並同步記憶」，檢查本機的對話、記憶及日記筆數。
6. 選「使用本機 → 上傳」，建立這份白龍的第一個雲端版本。

之後新增了互動，離開這台電腦前，重做檢查與比較，選擇本機版本上傳。

## 換電腦接續

1. 先在舊電腦同步完成，再關閉舊電腦的白龍。
2. 在新電腦開啟這一版白龍，登入自己的 ChatGPT 帳號。
3. 在同步視窗匯入同一份 Google OAuth JSON，登入同一個 Google 帳號。
4. 檢查雲端版本，**選擇原本的白龍版本**，不要選「建立新的白龍雲端紀錄」。
5. 按「比較並同步記憶」，選「使用雲端 → 套用本機」。

即使新電腦的 ChatGPT 登入註冊 ID 不同，程式也會將邏輯記憶套用到目前登入帳號的檔案，並保留原白龍的固定角色 ID。

## 發現未同步或不同版本時

只要兩份紀錄不同，就會出現選擇視窗，沒有自動覆蓋：

| 選項 | 結果 |
|---|---|
| 使用本機 → 上傳 | 將本機紀錄新增為雲端版本，舊雲端版本仍保留 |
| 使用雲端 → 套用本機 | 先備份本機，再完整套用所選的雲端紀錄 |
| 取消 | 不覆蓋本機，也不新增雲端版本 |

預設按鈕為「取消」。如果兩份內容完全相同，則只確認同步狀態，不產生重複版本。

版本下拉選單標示時間、角色 ID 尾碼及「最新／歷史」。選到歷史版本也可以還原，請先核對筆數和時間。此版以整份紀錄為單位選擇，**不會自動混合兩台電腦的記憶**。

## 同步內容與保存方式

包含：`Character.md`、近期及完整對話與摘要、長期記憶、親密信任與心情、觀察日記及其事件狀態。

不包含：ChatGPT／Google 登入資料、OAuth 用戶端設定、桌面快照、程式素材、Codex 的電腦專用通知命令與啟動設定。

雲端使用 Google Drive 的 **應用程式專屬資料空間**，不會顯示為一般 Drive 資料夾，也不要求讀取整個 Google Drive。同步紀錄可從白龍的版本清單查看。

本版雲端快照為 JSON 資料，由 Google 帳號授權控管，**尚未提供另外一層由使用者密碼加密的端對端加密**。不會呼叫 LLM 處理同步內容。

每次上傳都新增版本，保留歷史。暫不自動清除舊版本；資料會占用 Google Drive 空間，單一快照上限為 32 MB。

## 備份、斷線與衝突

- 下載前的本機備份放在 `CloudSync/Transactions/`，其中 `snapshot-before.json` 保存套用前的邏輯資料。
- 套用中途出錯會還原；若程式意外中斷，下次啟動會嘗試依交易紀錄復原。
- 上傳前會重新檢查本機及雲端是否在比較後又變更。偵測到更新會停止並要求重新比較。
- 雲端版本採新增保存；即使意外同時從兩台上傳，也不會直接覆寫對方的歷史。後續仍須由使用者選擇版本，這不代表已支援多台同時自動合併。
- 網路中斷或授權失效時，不假定同步成功。若取消時上傳已開始，請重新檢查版本，確認 Google 是否已收到該版本。
- 平常聊天仍使用本機資料，沒有按同步就不會背景上傳。每次換電腦前，請記得先同步。

## 驗證範圍

已進行離線測試，涵蓋版本選擇、取消、不同登入 ID 還原、資料驗證、備份、中途失敗回滾、重啟恢復、Google 權杖加密及授權錯誤。

**因尚未提供 OAuth 用戶端，實際 Google 登入與 Drive 上下載仍待你依上列步驟設定後驗收。** 離線測試不代表已完成真實雲端同步。
