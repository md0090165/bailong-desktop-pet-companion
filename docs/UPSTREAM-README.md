# 白龙桌宠 0.3.3

普通使用者请下载Releases里的 **bailong-desktop-pet-v0.3.3-windows-x64.zip**。解压后双击BailongPet.exe；无需Python。

白龙桌宠 v0.3.3 —— 不懂代码也能用

适用电脑：Windows 10 / Windows 11，64位Intel或AMD电脑。
本次已在Windows 11上验证。没有在另一台实体电脑上测试。
不支持macOS、Linux或32位Windows；Windows ARM电脑尚未验证。

一、下载哪一个文件？

在GitHub项目页面找到Releases（发布版本），打开最新的v0.3.3，
在Assets（附件）里下载：
bailong-desktop-pet-v0.3.3-windows-x64.zip

这是给普通使用者的完整包，程序、运行环境、动画和点击音效都在里面。
不要下载repository.zip，也不要选择GitHub自动提供的Source code (zip)。
那两种是给开发者看的源码，不含完整运行环境。

二、安装和第一次打开（不用输入命令）

1. 下载完后，右键点击ZIP文件，选择“全部提取”。
2. 提取到你容易找到的文件夹，例如“文档”中的“白龙桌宠”。
3. 等待解压完成，再打开解压后的BailongPet文件夹。
4. 找到BailongPet.exe，双击它。
5. 等待角色出现，启动时会准备全部动作，可能需要几十秒；等待准备窗口完成即可。

到这里就可以使用了。不用安装Python，不用安装开发工具，不用先打开GPT。
为了减少点击卡顿，程序会在启动时把动作准备到内存里，启动时间和内存占用比旧版增加。
不要在压缩包预览窗口里直接启动程序。
不要只把EXE拖到桌面：它旁边的_internal、outputs和app文件夹也要保留。
想从桌面打开，可右键BailongPet.exe，选择“显示更多选项”→“发送到”→“桌面快捷方式”。

三、怎么操作？

单击角色：随机播放动作，对应台词显示4秒。
快速双击角色：查询额度；查询动画只播一次，随后恢复待机。
按住左键拖动：播放拖拽动作；松手后播放2秒落地，再恢复待机。
拖到屏幕边缘：会停住，角色不会被拖出屏幕。
右键角色：可手动选择动作；最下面的“退出桌宠”可关闭桌宠。
平时自动按4:1的概率播放两套待机动画。

四、额度查询需要什么？

只玩桌宠：无需安装GPT或登录账号，解压后可以离线播放。
查询额度：需要在自己的电脑安装Codex，并登录自己的ChatGPT账号，且网络正常。
额度是Codex账户的5小时 / 一周额度，不代表ChatGPT网页所有模型的额度。
仅登录ChatGPT网页，并不等于已经登录本机Codex。
官方应用说明：https://learn.chatgpt.com/docs/app

没有安装或登录Codex时，双击可能显示“找不到Codex”或“暂时查不到额度”。
这不影响待机、单击动作、拖动和右键菜单。
发行包不带作者的账号、登录凭证或剩余额度，每个人读取自己的账号。

五、想在打开GPT时自动启动桌宠？（可选）

双击“开启随GPT自动启动.cmd”，等待出现“已开启”提示。
以后登录Windows时，后台助手会自动运行；打开GPT后约2秒启动桌宠。
目前识别微软商店版Codex / ChatGPT。其他安装形式未验证，可手动打开EXE。
手动退出桌宠后，不会立即重新出现；下次重新打开GPT才会再启动。
双击“关闭随GPT自动启动.cmd”可以关闭这项功能。
这些设置不需要输入代码。

如果要移动或删除桌宠文件夹：先关闭自动启动，再移动；移好后可重新开启。
从旧版本升级时：先退出旧桌宠，并用旧文件夹里的关闭功能停止旧助手。
若已有旧助手仍在后台运行，新助手可能要等下次登录Windows才接管。

六、打不开时怎么办？

提示找不到文件 / 缺少DLL：重新“全部提取”完整包，不要仅复制EXE；
也不要删除_internal或其他文件夹。

双击后没看到角色：先等待动作准备窗口结束，再检查屏幕右下区域；
已经打开过时，重复双击不会再出现第二只。

查不到额度：先确认Codex本身能登录和使用，并检查网络或代理。
临时网络错误会自动重试一次，最多可能等待约40秒；登录失效不会反复重试。
若仍失败，可将app文件夹里的额度查询日志.jsonl反馈给作者；该日志只记录错误类别、阶段、时间和耗时，不记录账号、凭证或额度数值。
桌宠的普通动作无需这些条件。

自动启动没有生效：先确认开启时出现成功提示，并检查Windows启动应用是否被禁用；
如果系统禁用Windows脚本宿主，这项可选功能可能不可用，仍可手动双击EXE。

Windows提示未知发布者：本版还没有数字签名。请核实下载来源；
若被安全软件拦截，把提示反馈给作者，不要为了运行程序关闭杀毒软件。

需要反馈运行问题：双击“检查桌宠.cmd”，等待检查完成，
把生成的“检查报告.json”和出错提示发给项目作者。
检查不会发送聊天，也不会包含账号登录凭证。

七、如何卸载？

右键角色选择“退出桌宠”。若开过自动启动，先双击关闭功能。
再删除整个BailongPet文件夹和自己创建的桌面快捷方式即可。

八、这个版本包含什么？

两套待机，十套随机差分，新版困倦，拖拽，2秒落地，查询：共15段透明动画。
所有动作采用固定尺寸校准，查询只播一次；全部动作在启动时预加载，切换采用完整不透明画面，不使用导致闪烁的淡入淡出，额度百分比独立显示在进度条外。
256×256显示、最高512×512内部播放帧（按屏幕缩放匹配清晰度，降低内存占用），带点击音效、屏幕边界限制。
